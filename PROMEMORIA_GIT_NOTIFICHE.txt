QUANDO VORRÒ RIPRENDERE LA FEATURE NOTIFICHE
--------------------------------------------

Non lavorare direttamente sul vecchio branch.

1. Partire dall'ultima versione di develop:

git checkout develop
git pull

2. Creare un nuovo branch:

git checkout -b fix/notifiche-reminder-eventi-v2

3. Recuperare i commit originali, dal più vecchio al più recente:

git cherry-pick ef482f0 325dfdb 1ddce39 2abb606 eb236b2 d6ba584 201a834

4. Se compaiono conflitti:

- aprire i file segnalati;
- risolvere i conflitti;
- eseguire:

git add .
git cherry-pick --continue

Per annullare completamente il cherry-pick in caso di problemi:

git cherry-pick --abort

5. Correggere gli errori della feature.

6. Pulire la build e ricompilare:

rmdir /s /q .next
npm run build

7. Avviare il progetto e testare tutto:

npm run dev

8. Pubblicare il nuovo branch:

git push -u origin fix/notifiche-reminder-eventi-v2

9. Creare una Pull Request verso develop.

10. Solo dopo i test su develop, portare develop in master.
